01 · 문제

메신저로 보내기엔 영상이 너무 큽니다

메신저로 영상을 보내다 보면 용량 제한에 자주 걸립니다.

영상을 줄이려면 인코딩 프로그램을 열고, 영상 길이에 맞춰 비트레이트(1초에 쓰는 데이터 양)를 직접 계산해야 합니다.

그래서 원하는 용량만 적으면 나머지는 앱이 알아서 하도록 만들었습니다. 비트레이트는 앱이 영상 길이로 계산하고, 압축에는 같은 화질을 더 작은 용량에 담는 AV1 코덱을 씁니다.

화질을 기준으로 하는 모드, 비트레이트를 직접 정하는 모드, 자동 모드도 함께 넣었습니다.

02 · 쓰는 사람 기준

친구에게 바로 보낼 수 있는 앱

친구들과 나눠 쓰는 앱이라, 받는 사람이 따로 아무것도 설치하지 않아도 되는 것이 가장 중요했습니다.

1

실행 파일 하나, 10MB 이하

메신저로 바로 보낼 수 있도록 실행 파일 하나를 10MB 아래로 맞췄습니다.

2

ffmpeg 자동 설치

영상을 변환하는 엔진(ffmpeg)이 없으면 설치할지 물어본 뒤 알아서 내려받습니다. 관리자 권한은 필요 없습니다.

UI 개선 후 (Pillow 추가)13.9MB
안 쓰는 이미지 모듈 제외10.61MB
일본어·중국어 인코딩 표 제외9.9MB

폴더 형태로 배포하면 실행 시간이 1.7초에서 0.76초로 줄었습니다.

하지만 그러면 받는 사람이 압축을 풀어야 합니다. 그래서 실행 속도보다 파일 하나로 끝나는 쪽을 골랐습니다.

03 · 디테일

작은 부분까지 손봤습니다

1

부드러운 곡선

앱 화면을 그리는 Tkinter는 둥근 모서리를 계단처럼 거칠게 그립니다. 4배 크기로 그린 뒤 줄여서 붙이는 방식으로 바꿔 부드럽게 만들었습니다.

2

AMD 그래픽카드 지원

그래픽카드로 인코딩하는 GPU 모드에 AMD를 추가하고, RX 9060 XT로 동작을 확인했습니다.

3

원인을 찾아 고친 버그

작업 표시줄 아이콘이 바뀌지 않던 문제는 아이콘을 엉뚱한 창에 지정해서 생긴 것이었습니다. 최상위 창을 찾아 지정하도록 고쳤습니다.

4

여러 파일 한 번에

영상 여러 개를 한 번에 끌어다 놓으면 순서대로 처리합니다. 처리 중에는 언제든 중단할 수 있습니다.
