AV1 Drop Encoder

보내기 전에,
원하는 용량으로.

메신저 용량 제한에 맞춰 영상을 원하는 크기로 압축하는 Windows 앱입니다. 창에 끌어다 놓으면 끝납니다.

용량 입력→영상 드롭→완성
Claude Code로 개발
10MB 이하실행 파일 하나
3종CPU · NVIDIA · AMD 인코딩
4가지용량 · 화질 · 비트레이트 · 자동

01 · 문제

영상은 큰데,
메신저는 작습니다.

메신저로 영상을 보내면 용량 제한에 자주 걸립니다. 줄이려면 인코딩 도구를 열고 비트레이트를 계산해야 합니다.

원하는 용량만 적고, 영상을 끌어다 놓으면 끝나게 만들었습니다. 앱이 영상 길이로 비트레이트를 거꾸로 계산합니다. 화질 기준, 비트레이트 직접 지정, 원본 분석 자동 모드도 함께 넣었습니다.

02 · 쓰는 사람 기준

친구에게
보낼 수 있는 앱.

친구들과 나눠 쓰려고 만든 앱입니다. 그래서 받는 사람이 아무것도 설치하지 않아도 되는 것을 가장 먼저 정했습니다.

1

파일 하나,
10MB 이하

메신저로 바로 보낼 수 있게 실행 파일 하나를 10MB 밑으로 맞췄습니다.

2

ffmpeg는
알아서

인코딩 엔진(ffmpeg)이 없으면 물어본 뒤 내려받아 설치합니다. 관리자 권한은 필요 없습니다.

UI 개선 후 (Pillow 추가)13.9MB
안 쓰는 이미지 모듈 제외10.61MB
일본어·중국어 인코딩 표 제외9.9MB

빠른 것보다,
파일 하나가 중요했습니다.

폴더 형태로 배포하면 실행이 1.7초에서 0.76초로 빨라지는 것을 실측했습니다. 하지만 받는 사람이 압축을 풀어야 합니다. 실행 속도 대신 단순한 배포를 택했습니다.

03 · 디테일

작은 앱이라도
끝까지.

1

매끈한
곡선

Tkinter 기본 캔버스는 곡선을 계단처럼 그립니다. 도형을 4배 크기로 그린 뒤 줄여서 붙이는 방식으로 화면 그리기를 통째로 바꿨습니다.

2

AMD도
직접 확인

NVIDIA만 지원하던 GPU 인코딩에 AMD를 추가했고, 제 RX 9060 XT로 실제 동작을 확인했습니다.

3

버그는
원인까지

작업표시줄 아이콘이 바뀌지 않는 문제는, 아이콘을 엉뚱한 창에 지정하고 있던 것이 원인이었습니다. 진짜 최상위 창을 찾아 고쳤습니다.

4

여러 개도
한 번에

여러 영상을 한 번에 놓으면 순서대로 처리합니다. 처리 중 언제든 중단할 수 있습니다.

코드는 AI가,
