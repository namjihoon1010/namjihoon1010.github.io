운영자가 없어도
도는 서버.

입대를 앞두고, 친구들이 쓰는 마인크래프트 서버를 혼자 돌아가게 만들었습니다. 디스코드 봇 하나로 켜고, 끄고, 백업하고, 복구합니다. 폰만 있으면 어디서든 관리할 수 있습니다.

01 · 문제

내가 없으면
멈추는 서버.

처음 서버는 노트북에서 직접 켜고 끄는 방식이었습니다. 운영자가 자리에 없으면 아무도 서버를 켤 수 없고, 꺼지거나 망가져도 알 수 없었습니다.

입대하면 몇 달씩 PC 앞에 앉을 수 없습니다. 그래서 목표를 정했습니다. 사람이 PC를 만지지 않아도 켜지고, 지켜지고, 고쳐지는 서버.

02 · 구조

PC는 그대로,
서버만 필요할 때.

PC 전원을 원격으로 켜고 끄는 건 실패하면 되돌릴 방법이 없습니다. 그래서 PC는 항상 켜 두고, 디스코드 봇이 게임 서버만 필요할 때 켜고 끕니다. 서버가 꺼져 있는 동안 PC는 평소처럼 쓸 수 있습니다.

친구들은 중계 터널로 접속해서 집 IP가 드러나지 않습니다. 게임 데이터와 백업은 서로 다른 디스크에 둬서, 하나가 망가져도 다른 하나는 남습니다.

친구들PC(자바)와 모바일(베드락) 모두 접속
↓
중계 터널집 IP 숨김, 포트포워딩 불필요
↓
집 데스크톱 · 항상 켜짐
게임 서버Paper, SSD
디스코드 봇전체 제어, 부팅 시 자동 실행
백업증분 백업, HDD
03 · 자동화

알아서 하는 일들.

1

아무도 없으면
꺼집니다

10분 동안 접속자가 없으면 백업 후 자동 종료합니다. 평소에는 메모리를 거의 쓰지 않습니다.

2

10분마다
백업합니다

바뀐 파일만 저장하는 증분 백업입니다. 최근 2시간은 10분 단위, 48시간까지는 1시간 단위로 남기고 나머지는 합칩니다.

3

꺼지면
다시 켭니다

서버가 갑자기 꺼지면 자동으로 재시작합니다. 3분 안에 3번 넘게 꺼지면 멈추고 운영자에게 알립니다.

4

로그인 없이
복귀합니다

윈도우 업데이트로 PC가 재부팅돼도 로그인 없이 봇과 터널이 자동으로 다시 뜹니다.

5

검증한 뒤에만
업데이트합니다

서버를 켤 때마다 새 버전을 확인하고, 내려받은 파일이 온전한지 검사한 뒤에 교체합니다. 문제가 있으면 쓰던 버전을 그대로 씁니다.

6

필요한 것만
알려 줍니다

새 버전, 재부팅 대기, 백업 실패처럼 운영자가 판단할 일만 DM으로 받습니다. 친구들 채팅방에는 공지가 필요할 때만 보냅니다.

04 · 권한 설계

누구나 켤 수 있고,
위험한 일은 운영자만.

친구 누구나 서버를 켜고 상태를 볼 수 있게 했습니다. 월드를 되돌리거나 PC를 재부팅하는 명령은 운영자만 쓸 수 있고, "확인" 단어를 한 번 더 입력해야 실행됩니다.

/서버켜서버를 켜고, 다 켜지면 알림누구나
/서버꺼안전하게 저장 후 종료, 종료 시 백업. 접속자가 있으면 운영자만조건부
/상태접속 인원, 명단, 서버 성능(TPS)누구나
/백업즉시 증분 백업운영자
/복구원하는 백업 시점으로 월드 복구. 현재 월드는 따로 보존운영자
/버전업백업 → 종료 → 버전 교체. 호환 경고와 되돌리기 포함운영자
/재부팅서버를 안전하게 끈 뒤 PC 재부팅운영자

14개 중 일부

05 · 운영하며 고친 것

돌려 보고 나서야
보인 문제들.

1

숨겼던 집 IP가
새고 있었습니다

모바일 접속 플러그인이 중계 주소가 아닌 집 IP를 플레이어에게 알려 주고 있었습니다. 플러그인을 내부 주소에만 묶고 전용 터널로 우회시킨 뒤, 실제 폰 접속으로 확인했습니다.

2

결제 실패 하나로
주소가 사라졌습니다

중계 서비스 갱신 결제가 실패하자 터널과 주소가 전부 삭제됐습니다. 다시 만든 뒤, 같은 일이 생겨도 누구나 복구할 수 있게 갱신 전 확인할 것과 함께 고칠 곳을 문서로 남겼습니다.

3

PC를 쓰는 사람에게
양보하게 했습니다

제가 없는 동안 형이 가끔 이 PC를 씁니다. 그래서 메모리를 12GB 고정에서 2~10GB 유동으로 바꾸고 서버의 CPU 우선순위를 낮췄습니다. PC 앞에 앉은 사람이 먼저입니다.

06 · 만든 방식

코드는 AI가,
운영은 제가.

코드는 Claude로 작성했습니다. 무엇이 필요한지, 어떤 위험을 막을지, 실제로 잘 도는지는 직접 정하고 확인했습니다. 바꿀 때마다 버전과 변경 기록을 남겨서, 문제가 생기면 92개 버전 중 어디로든 되돌릴 수 있습니다.
