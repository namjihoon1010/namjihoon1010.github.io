01 · 문제

처음엔 제가 없으면
서버가 멈췄습니다

처음에는 제 노트북에서 서버를 직접 켜고 껐습니다.

제가 없으면 아무도 서버를 켤 수 없었고, 서버가 꺼져도 알 방법이 없었습니다.

입대하면 몇 달 동안 PC를 만질 수 없습니다. 그래서 아무도 관리하지 않아도 스스로 켜지고, 문제가 생기면 알아서 복구되는 서버를 만들기로 했습니다.

02 · 구조

PC는 켜 두고
서버만 켜고 끕니다

PC 전원을 원격으로 켜고 끄다가 실패하면, 집에 아무도 없을 때 되돌릴 방법이 없습니다.

그래서 PC는 항상 켜 두고, 디스코드 봇이 게임 서버 프로그램만 켜고 끄게 했습니다.

친구들은 중계 터널을 거쳐 접속하기 때문에 집 IP 주소가 드러나지 않습니다.

게임 데이터는 SSD에, 백업은 HDD에 따로 두어 한쪽 디스크가 망가져도 다른 쪽이 남습니다.

친구들PC(자바)와 모바일(베드락) 모두 접속
↓
중계 터널집 IP 숨김, 포트포워딩 불필요
↓
집 데스크톱 · 항상 켜짐
게임 서버Paper, SSD
디스코드 봇전체 제어, 부팅 시 자동 실행
백업증분 백업, HDD
03 · 자동화

사람 없이
돌아가는 기능

1

아무도 없으면 꺼짐

10분 동안 아무도 접속하지 않으면 백업한 뒤 서버를 끕니다. 꺼져 있는 동안에는 PC 메모리를 거의 쓰지 않습니다.

2

10분마다 백업

바뀐 파일만 골라 저장합니다. 최근 2시간은 10분 단위, 48시간까지는 1시간 단위로 백업을 남깁니다.

3

꺼지면 자동 재시작

서버가 갑자기 꺼지면 자동으로 다시 켭니다. 3분 안에 3번 넘게 꺼지면 다른 문제가 있다고 보고, 재시작을 멈춘 뒤 저에게 알립니다.

4

로그인 없이 복귀

윈도 업데이트로 PC가 재부팅돼도, 아무도 로그인하지 않은 상태에서 봇과 터널이 다시 켜집니다.

5

검증한 뒤에만 업데이트

서버를 켤 때마다 새 버전을 받아, 파일이 온전한지 검사한 뒤에만 교체합니다. 문제가 있으면 쓰던 버전으로 켭니다.

6

필요한 알림만

새 버전 출시, 재부팅 대기, 백업 실패처럼 제가 판단해야 하는 일만 DM으로 받습니다.

04 · 매일 점검

매일 새벽 5시에
서버를 점검합니다

입대한 뒤에는 서버에 문제가 생겨도 제가 바로 알아차리기 어렵습니다.

그래서 매일 새벽 5시에 Claude(AI)가 서버 상태를 점검하고, 디스코드 봇이 그 결과를 제 DM으로 보내도록 했습니다.

점검은 읽기 전용이라 서버를 건드리지 않습니다. 무엇을 문제로 볼지는 제가 기준을 정했고, 보고서는 폰에서 한눈에 읽히도록 열 줄 안팎으로 옵니다.

1

살아 있는지

봇과 접속 터널이 켜져 있는지 확인합니다. 서버는 아무도 없으면 꺼지도록 만들었기 때문에, 꺼져 있는 것 자체는 문제로 보지 않습니다.

2

백업과 디스크

마지막으로 서버를 끈 뒤 백업이 남았는지, 디스크 여유가 50GB 이상인지 확인합니다.

3

접속 주소와 오류

모바일 접속 주소가 바뀌지 않았는지, 최근 24시간 로그에 반복되는 오류나 크래시가 없는지 봅니다. 문제가 있으면 원인과 해결 방법을 한 줄로 함께 적습니다.

4

서버 소식

최근 24시간 동안 누가 접속했고 어떤 일이 있었는지 두세 줄로 요약합니다. 직접 접속하지 않아도 서버 분위기를 알 수 있습니다.

05 · 권한 설계

위험한 명령은
운영자만 쓸 수 있습니다

서버 켜기와 상태 확인은 누구나 할 수 있습니다.

월드 복구와 PC 재부팅은 운영자만 쓸 수 있고, 실수를 막기 위해 "확인"을 한 번 더 입력해야 실행됩니다.

/서버켜서버를 켜고, 다 켜지면 알림누구나
/서버꺼안전하게 저장 후 종료, 종료 시 백업. 접속자가 있으면 운영자만조건부
/상태접속 인원, 명단, 서버 성능(TPS)누구나
/백업즉시 증분 백업운영자
/복구원하는 백업 시점으로 월드 복구. 현재 월드는 따로 보존운영자
/버전업백업 → 종료 → 버전 교체. 호환 경고와 되돌리기 포함운영자
/재부팅서버를 안전하게 끈 뒤 PC 재부팅운영자

06 · 운영하며 고친 것

운영하면서
고친 문제

1

숨겼던 집 IP가 새고 있었습니다

모바일 접속용 플러그인이 중계 주소 대신 집 IP를 알려 주고 있었습니다. 플러그인을 내부 주소에만 연결하고 전용 터널로 돌린 뒤, 폰으로 접속해 집 IP가 보이지 않는 것을 확인했습니다.

2

결제 실패로 주소가 사라졌습니다

중계 서비스 요금 결제가 실패하자 터널과 접속 주소가 전부 지워졌습니다. 다시 만든 뒤, 제가 없어도 누구나 복구할 수 있게 절차를 문서로 남겼습니다.

3

PC 쓰는 사람에게 양보

제가 없는 동안에는 형이 가끔 이 PC를 씁니다. 서버 메모리를 12GB 고정에서 2~10GB 유동으로 바꾸고, 서버 우선순위를 낮춰 PC를 쓰는 데 불편이 없게 했습니다.

07 · 만든 방식

코드는 AI가 쓰고
운영은 제가 합니다

코드는 Claude로 작성했습니다.무엇을 만들지, 어떤 위험을 막을지는 제가 정하고 직접 확인했습니다.바꿀 때마다 기록을 남겨서 91개 버전 중 어디로든 되돌릴 수 있습니다.
